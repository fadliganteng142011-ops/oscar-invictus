# OSCAR INVICTUS

Flutter project sederhana untuk stress-test komputasi lokal pada perangkat sendiri.

## Struktur
- pubspec.yaml
- lib/main.dart

## Build
1. Jalankan `flutter pub get`
2. Jalankan `flutter build apk --release`
3. APK berada di `build/app/outputs/flutter-apk/app-release.apk`

Project ini tidak ditujukan untuk mengganggu perangkat atau aplikasi lain.
